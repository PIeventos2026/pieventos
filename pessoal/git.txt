**Como atualizar no repositorio**

Atualizou algo no codigo e quer mandar pro git?
Tome 5 passos de como fazer isso até aprender

1. abre um terminal em Bash


2. git status        
//pra saber o estado do arquivo


3  git add .                
// pra add todas as suas mudanças 


4.git commit -m "oque vc alterou"
// pra mostrar para as outras oq vc alterou

5.git push
// pra de fato mandar pro repositorio
