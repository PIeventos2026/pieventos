# Eventos Fatec

## 📌 Objetivo

O projeto **Eventos Fatec** foi desenvolvido com o objetivo de criar uma plataforma institucional para divulgação e organização de eventos acadêmicos da FATEC.  

A aplicação busca facilitar o acesso às informações dos eventos, permitindo uma navegação simples, moderna e intuitiva para alunos, professores e visitantes.
